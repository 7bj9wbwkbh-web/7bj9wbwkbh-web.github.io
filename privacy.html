Overview

Home Integration is a private, personal home-automation application used by a single household. It is not a commercial product and does not offer public sign-ups. Its only user is the owner, who uses it to read status from his own Google Nest devices.

This website is static. It does not run scripts, set cookies, or collect personal information from visitors.

Data accessed

The application accesses the owner's own Nest device data through Google's Device Access and Smart Device Management API, using the sdm.service scope. That data is limited to devices in the owner's household, such as cameras, a doorbell, a thermostat, and a display.

The application uses this data only to show the owner the status of his own devices. It does not access anyone else's Google account or devices.

How data is used

Nest device data and the OAuth tokens used to retrieve it are used only to provide that status view to the owner. They are not sold, not shared with third parties, and not used for advertising, retargeting, or any other commercial purpose.

OAuth tokens are stored privately on the owner's own systems. They are not published on this website.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

In particular:

  • Google user data is used only to provide the user-facing feature of showing the owner the status of his own Nest devices.
  • Google user data is not transferred to others, except if the owner directs it, if required for security, or if required by law.
  • Humans do not read this data except the owner viewing his own device status.
  • Google user data is not used for serving advertisements and is not sold.
  • Google user data is not used to determine creditworthiness or for lending.
  • Google user data is not used to train generalized artificial-intelligence or machine-learning models.

Revoking access

The owner can revoke the application's access at any time:

  • From the Google Account permissions page at https://myaccount.google.com/permissions.
  • From Nest partner connections, where the Device Access connection can be removed.

After access is revoked, the application can no longer read Nest device data. Tokens stored on the owner's systems can be deleted there as well.
